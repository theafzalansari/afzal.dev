## ✨ Overview

Afzal.dev is a modern, responsive personal portfolio built to represent my journey as a developer and showcase the work I've created while learning and experimenting with modern technologies.

The portfolio focuses on the intersection of:

- 💻 **Software Engineering**
- 🌐 **Full Stack Web Development**
- 🧠 **Artificial Intelligence**
- 📊 **Data Analysis**
- 🧩 **Problem Solving & DSA**

Rather than simply listing technologies, the portfolio is designed to demonstrate them through real projects, experiences, achievements, and continuous learning.

## ⚙️ Installation

```bash
# 1. Clone the repository
git clone https://github.com/theafzalansari/afzal.dev.git

# 2. Navigate into the project directory
cd afzal.dev

# 3. Install dependencies
npm install

# 4. Start the development server
npm run dev
```

The app will be available at `http://localhost:5173` by default.

---

## 🔐 Environment Variables

Create a `.env` file in the root of the project and add the EmailJs Api's :

```env
VITE_SERVICE_ID=
VITE_TEMPLATE_ID=
VITE_PUBLIC_KEY=
```

> ⚠️ Never commit your `.env` file. Make sure it's included in `.gitignore`.
